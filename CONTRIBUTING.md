# Contributing

**Spendly** is a personal modified copy of Flow. It is not the upstream project ([flow-mn/flow](https://github.com/flow-mn/flow)), and it is not looking for feature requests, issues, or translators.

You can still fork the code under the
[GNU GPL v3](./LICENSE). Pull requests are not expected. If you open one
anyway:

1. Branch off `main`
2. Keep the change small and aligned with this simplified tracker
3. Run `flutter analyze` and `flutter test`
4. By contributing, you license your work under GPL-3.0, same as the rest of
  the repository

Do not send patches or questions about this repo to the original Flow
maintainer.

For how to build and test, see [README.md](./README.md#development).
Attribution for the original work is in [NOTICE](./NOTICE).
